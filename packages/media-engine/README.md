# Media engine boundary — planned

Phase 3: FFprobe inspection, proxies, non-destructive timeline, FFmpeg render
jobs, trims, crops, captions, audio gain and revisioned artifacts. Manual edits
and AI edit proposals must use the same validated operation schema.

Phase 5: timestamped transcription, scene/audio signals and optional visual
analysis; suggest configurable clips (for example, 30 seconds), explain each
candidate and allow human selection/re-edit. No promise of virality.

Source files remain unchanged. Workers use argument arrays, scoped paths,
cancellation and resource limits. FFmpeg distribution/build license and codec
choices are a packaging decision; no binary is bundled by the template.
